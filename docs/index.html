Report an outcome

Open to everyone. Validators fetch your evidence URL and an LLM must confirm it supports the claim, otherwise nothing is recorded. Unregistered reporters carry a low default weight.

Challenge an event

Think a recorded outcome is false? Submit different counter-evidence. If validators find the claim contradicted, the event is reversed on-chain. Click an event in History to fill its ID.

Owner tools only tune source weights and half-life. The owner cannot write or edit scores.

①Evidence, not trust

Each outcome needs a public URL. Validators fetch it and reach LLM consensus on whether it supports the claim. Unsupported claims never touch the score.

②Open, with weights

Anyone can report at a low default weight; registered sources get more. Impact = delta × weight, and scores halve every half-life.

③Challenge & reverse

Anyone can submit counter-evidence. If the claim is contradicted, the event is reversed on-chain. The owner has no power over scores.
